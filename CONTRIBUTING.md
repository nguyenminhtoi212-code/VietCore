# CONTRIBUTING TO METROLIST MUSIC

Thank you for your interest in contributing to Metrolist Music! We welcome contributions to improve playback performance, user interface, audio engine integration, and overall stability. Please follow the guidelines below to keep the codebase clean and maintainable.

## 1. CODE OF CONDUCT
- Maintain professionalism and respectful communication across all issues, pull requests, and discussions.
- Keep discussions focused on technical improvements, feature suggestions, and bug resolution.

## 2. DEVELOPMENT GUIDELINES
- **Language**: All source code must be written in Kotlin or Java.
- **Architecture**: Follow modern Android architecture guidelines (MVVM, Jetpack components, and AndroidX Media3 / ExoPlayer integration).
- **Formatting**: Align code with standard Android Studio formatting and lint specifications.
- **Documentation**: Provide concise inline comments for audio playback logic, background service handling, and custom UI components.

## 3. PLAYBACK & UI STANDARDS
- **Performance**: Ensure background audio service efficiency without memory leaks, unexpected interruptions, or excessive battery drain.
- **User Interface**: Adhere to clean Material Design guidelines with smooth animations and responsive layouts for various screen sizes.
- **Media Controls**: Test all playback controls, media session events, lock screen widgets, and notification controls to ensure seamless playback management.

## 4. PULL REQUEST PROCESS
1. Fork the repository and create your feature branch (`feature/your-feature-name` or `bugfix/issue-description`).
2. Implement your changes adhering to the development standards above.
3. Test audio playback, playlist management, and background playback state handling.
4. Submit a Pull Request detailing the changes made and the motivation behind them.
5. Await code review and address any feedback prior to merging.

## 5. BUG REPORTS & FEATURE SUGGESTIONS
- Submit bug reports and feature ideas via GitHub Issues.
- Provide device details (Device Model, Android OS version) and step-by-step instructions to reproduce any playback or UI issues.
- Attach logcat traces if reporting crashes or playback errors.
